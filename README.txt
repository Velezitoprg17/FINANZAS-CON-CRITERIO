FINANZAS CON CRITERIO — INSTRUCCIONES

1. Descarga y descomprime la carpeta.
2. Mantén index.html, styles.css, script.js y fuentes.md en la misma carpeta.
3. Abre index.html con Chrome, Edge, Firefox o Safari.
4. Para exponer en el salón, usa pantalla completa en el navegador (F11 en muchos computadores).
5. La página no necesita base de datos ni servidor.

NOTAS
- Se necesita conexión a internet para abrir los enlaces externos y cargar la fuente tipográfica remota. La página y sus interacciones básicas funcionan localmente; si no hay internet, el navegador usará fuentes alternativas.
- El contenido es educativo y no constituye asesoría financiera.
- No se nombran aplicaciones específicas como vigiladas: primero debe verificarse la entidad jurídica y la actividad exacta en fuentes oficiales.
